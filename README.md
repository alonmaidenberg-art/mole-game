# תפוס את החפרפרת 🐹

משחק דפדפן קטן: לוחצים על החפרפרות לפני שהן נעלמות. כולל ארבעה עולמות, ארבע רמות, דמויות מיוחדות ואירועים נדירים.

## הרצה

אין צורך בבנייה. זה קובץ `index.html` אחד עם קבצי התקנה לצידו.
לבדיקה מקומית: `python3 -m http.server 8000` ואז לפתוח `http://localhost:8000`.

## פרסום ב-Netlify

גוררים את כל התיקייה (לא ZIP של תיקייה בתוך תיקייה) ל-Netlify Drop,
או מחברים את הריפו ב-Netlify (Build command ריק, Publish directory `.`).

## התקנה לטלפון

כדי שכרום יציע **"התקן אפליקציה"** (ולא רק "הוסף קיצור דרך"), צריך את כל אלה, והם כבר כאן:
`manifest.webmanifest` עם אייקונים PNG בגדלים 192 ו-512, `sw.js`, וכתובת HTTPS.
בתפריט של המשחק יופיע גם כפתור "📲 התקן את המשחק" כשהדפדפן מאפשר.

אם בעבר הוספת את המשחק כקיצור דרך: למחוק אותו ולהתקין מחדש.

## קבצים

- `index.html` המשחק עצמו
- `manifest.webmanifest`, `sw.js` ההתקנה והעבודה בלי אינטרנט
- `icons/` סמל החפרפרת (`mole.svg` הוא המקור)
- `_headers` הגדרות מטמון ל-Netlify, כדי שעדכונים יגיעו מהר
